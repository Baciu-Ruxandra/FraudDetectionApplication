# FraudDetectionApplication

An end-to-end fraud detection system developed in Python, designed to identify potentially fraudulent transactions using machine learning techniques. The project covers the full workflow, including EDA, feature engineering, model training and evaluation, and application-level integration.

The application includes a user-facing interface that allows users to interact with the trained model and submit transaction data for fraud prediction. The backend logic is built using a modular architecture, with configuration files for flexibility and logging for debugging and traceability. Jupyter notebooks are provided for data exploration and experimentation, while the core functionality is implemented in reusable source modules.
